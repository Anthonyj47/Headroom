# Headroom

A simple budget planner that runs in the browser. Open `index.html` to use it.

## Files

| File | What it holds |
| --- | --- |
| `index.html` | The page structure: headings, forms and buttons |
| `styles.css` | How it looks: colours, fonts, layout and hover effects |
| `app.js` | How it works: budgets, bills, payday periods and saving |

Keep the three files in the same folder.

## Notes

- Everything you enter is saved in the browser you use, on that device only.
- There is no server and no account. Nothing is uploaded.
- Fonts load from Google Fonts when you are online and fall back to system fonts when you are not.

## Updating

Only upload the file or files that changed. Usually that is just `app.js`, or `styles.css` for a visual change.
