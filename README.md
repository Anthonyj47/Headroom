# Headroom

A simple budget planner that runs in the browser. Open `index.html` to use it.

- Everything you enter is saved in the browser you use, on that device only.
- There is no server and no account. Nothing is uploaded.
- Fonts load from Google Fonts when you are online and fall back to system fonts when you are not.

## Updating

1. Replace `index.html` with the new version.
2. In GitHub Desktop, check the changes, write a short summary, press **Commit**, then **Push origin**.
